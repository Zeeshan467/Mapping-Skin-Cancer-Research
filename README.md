## Overview

This repository provides research data and supporting resources for the project **Mapping Skin Cancer Research**.

The repository is intended to support research, data exploration, analysis, and scientific investigations related to skin cancer. It provides a centralized location for accessing the associated dataset and documenting its use in research activities.
